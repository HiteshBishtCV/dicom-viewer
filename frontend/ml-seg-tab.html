Platipy [cardiac] not installed
pip install "platipy[cardiac]"
Atlas (~50 MB) is downloaded automatically on first run and cached locally.

heartchambers_highres is a licensed TS task. Get a free research key: totalseg_get_license_key --email you@example.com
TotalSegmentator must already be installed. Licence is stored locally.
MONAI not installed
pip install 'monai[all]'
Uses the wholeBody_ct_segmentation bundle (~1 GB, 104-structure SegResNet). Downloaded automatically on first run and cached in ~/.cache/monai_bundles/.
MedSAM dependencies not installed
pip install transformers Pillow
MedSAM-ViT-B (~375 MB) is downloaded from HuggingFace on first run and cached in ~/.cache/huggingface/.
